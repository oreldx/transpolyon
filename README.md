# Transpolyon

Une app web légère pour monitorer mes daily commutes dans Lyon en utilisant l'Open Data de Grand Lyon (TCL & Vélo'v).

## Features

- Visualiser les stations (Vélo'v & TCL)
- Store des trajets en local storage
- Comparer les temps de trajets actuels sous différentes configurations
- Voir les tendances de trafic

## Stack

- Frontend: Vue
- Backend: Fastify
- Base de données: /
